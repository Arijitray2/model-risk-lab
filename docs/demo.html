Run the desk yourself

The full market-making engine, ported to JavaScript and running in your browser. Choose the true world and, separately, the model the desk believes. Presets carry the parameters calibrated to real SPY data. Everything is seeded — same seed, same run.

Reading the bottom chart. The teal dashed line is the edge the desk believes it is banking (half-spread per fill, measured against its own model). The orange dashed line is the true expected edge (measured against true fair value). The blue line is realised P/L. When the desk's model is right the three travel together; when it is wrong, the desk's belief keeps climbing while reality sinks — that gap is model risk in dollars. COVID-preset jump parameters (λ=3.68/yr, mean −31%) come from the real SPY chain of 16 Mar 2020.
